An advantage of the website download format is that there is more room to manipulate the data. Unlike the data product from the gtrendsR package, the data downloaded directly from the website has less columns and categories and is much less organized. This leaves room for individual data manipulation, allowing you to tailor the data how you see fit.

Use the gtrendsR package to collect data (use gtrendsR01.R program). Save the data into csv and R data formats. What are the differences between the two methods?

# install.packages("gtrendsR")
library(gtrendsR)

# Wait 10 seconds to avoid rate limiting
Sys.sleep(10)

# Query 5 years of trend data for all three terms
out <- gtrends(
  c("Trump", "Kamala Harris", "election"),
  onlyInterest = TRUE,
  geo = "US",
  gprop = "web",
  time = "today+5-y",
  category = 0
)

# Save the time series
df <- out$interest_over_time

# Plot the trends
plot(out)

# Another separate test query
Sys.sleep(10)
tg <- gtrends("tariff", time="all")

An advantage of the gtrendsR01 method is that the data is cleaner and organized better when the code is run; therefore, the plotting result is also cleaner, more visually appealing, and easier to read.

Due to repeated rate-limiting (429 status code errors) from the Google Trends API, the gtrendsR query would not render the plot in Quarto after too many times running the code. The original gtrendsR code is included for reproducibility. In place of the gtrends API plot, I downloaded the same Google Trends time-series data from online; this time frame shows the trends of these keywords over the past 12 months.
